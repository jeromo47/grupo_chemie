# SQL - Montaje operativo Chemie

Este bloque sirve para montar, paso a paso, la parte técnica de datos / SQL / automatización ligada a Chemie.

## Objetivo
Tener un espacio limpio para:
- guardar guías de Claude u otros modelos
- tomar decisiones técnicas
- probar scripts
- registrar errores y aprendizajes
- convertir ideas en un sistema usable

## Estructura
- `00_contexto/` → contexto base y notas de partida
- `01_guias_claude/` → respuestas, planes o guías externas
- `02_decisiones/` → decisiones técnicas ya tomadas
- `03_scripts/` → scripts, consultas y utilidades
- `04_pruebas/` → pruebas, resultados y logs cortos
- `05_checklists/` → pasos de montaje y validación

## Regla de trabajo
No mezclar aquí estrategia general de negocio salvo que afecte directamente al diseño técnico del sistema.
